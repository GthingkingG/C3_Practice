# C3 Practice

Apple Developer Academy C3 SwiftUI 연습 프로젝트 — 일정/이벤트 관리 미니 앱.

## 학습 목적
- SwiftUI 화면 라우팅 (`ContentView` → 다양한 뷰)
- MVVM 패턴 (`EventModel` + `EventViewModel`)
- 일정 / 타임테이블 / 히스토리 뷰 분리
- 디테일 뷰 네비게이션

## 주요 컴포넌트
| 파일 | 역할 |
|------|------|
| `C3_PracticeApp.swift` | @main 진입점 |
| `ContentView.swift` | 메인 뷰 |
| `EventModel.swift`, `EventViewModel.swift` | 이벤트 데이터 모델·ViewModel |
| `EventView.swift` | 이벤트 목록 뷰 |
| `TimeableView.swift` | 타임테이블 뷰 |
| `HistoryView.swift` | 히스토리 뷰 |
| `TaskDetailView.swift` | 작업 상세 뷰 |

## 빌드 & 실행
```bash
git clone https://github.com/GthingkingG/C3_Practice.git
open C3_Practice/C3_Practice.xcodeproj
```
